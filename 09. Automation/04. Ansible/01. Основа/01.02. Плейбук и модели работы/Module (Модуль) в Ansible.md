#flashcards/automation/Ansible
***
Если [[Tasks (Таски) в Ansible|таска]] - это обертка (пример: установить [[Nginx]]), желаемое состояние, то модуль - конкретный рабочий инструмент внутри таски, который работает с системой и выполняет всю работу.
- Модули, как правило, уже готовые для любых задач. Нужно просто взять шаблон и подставить нужные данные (пример: работа с файлами, [[Пакет|пакетами]], пользователями, сетями, БД и др.).
- Основан на принципе [[Идемпотентность|идемпотентности]].
***
***Пример (модуль [[Apt модуль Ansible|apt]]).***
```yaml
- name: установка git   # 1
  apt:                  # 2
    name: git           # 3
    state: present      # 4
```
1. Имя таски.
2. Имя модуля (здесь он для работы с пакетами Ubuntu).
3. [[Параметр модуля в Ansible|Параметр]] - какой пакет нужен.
4. Параметр - статус (должен быть установлен).
