#flashcards/automation/Ansible
***
Составляющие [[Play (Плей) в Ansible|плеев]] в [[Playbook (Плейбук, Сценарий) в Ansible|плейбуках]], конкретные шаги по настройке хостов.
- Описывает желаемое состояние хоста по принципу [[Идемпотентность|идемпотентности]].
***
***Правила работы.***
1. ***Строгая очередность*** - выполняются сверху вниз. Пока 1 не завершится, 2 не начнется.
2. ***Имя = лицо таски*** - каждая таска имеет строку `name:`, именно ее будем видеть в [[Терминал, Эмулятор терминала|терминале]].
3. ***Одна таска = одно действие*** - внутри таски нельзя мешать установку [[Утилита|утилиты]] и копирование файла. Одна таска дергает один [[Module (Модуль) в Ansible|модуль]].
***
***Пример.***
```yaml
- name: настройка окружения
  hosts: webservers
  become: yes
  
  tasks:
    - name: Обновить кэш
      # модуль для обновления
    - name: Установить vim
      # модуль для установки
    - name: Создать папку
      # модуль создания папок
```
