#flashcards/automation/Consul 
***
Один из самых популярных инструментов, реализующих процесс [[Service Discovery]].
- В его основе - [[Consul Server]] и [[Consul Client]].
***
***Роли работы.***
1. [[Service Registry (Реестр)|Реестр]].
2. [[Health Checker (Смотритель)|Смотритель]].
3. Интерфейс [[Протокол HTTP|HTTP]] [[API]] - для веб-запросов через Consul и получения [[IP-адрес|IP-адресов]] в формате JSON.
4. Встроенный [[Протокол DNS|DNS]]-сервер - может притвориться таким [[Сервер (Клиент Серверная Архитектура)|сервером]] для перехвата запросов и возврату нужного IP => можно работать с [[Микросервис|микросервисами]], которые умеют общаться только по [[Домен|домену]].
