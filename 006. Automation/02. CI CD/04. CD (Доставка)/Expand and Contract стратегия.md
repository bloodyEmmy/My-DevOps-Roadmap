#flashcards/automation/cicd
***
Используется для реализации [[Правило обратной совместимости при деплое|правила обратной совместимости]], чтобы избежать [[Даунтайм (Downtime)|даунтайма]] при работе с БД.
- ***Правило:*** Добавь новое => научи систему с этим работать => удали старое.
***
***Зачем нужна.***
Мы обновили БД, но [[CI CD Pipeline (Пайплайн)|пайплайн]] еще не успел изменить код, который с ним работает => ошибка.
***
***Состоит из 3 шагов.***
Разберем на примере переименовывания колонки.
1. ***Расширение (Expand) - [[Деплой|деплой]] №1.***
	- Вместо изменения имени мы создаем новую колонку рядом со старой.
	- Код пишем так, чтобы он читал данные из старой колонки, но записывал данные в обе.
2. ***Перенос данных + переподключение - деплой №2.***
	- Копируем данные из старой колонки в новую, где еще не было данных.
	- Код переключается на работу только с новой колонкой.
	- Программа работает с новой колонкой по новой логике.
3. ***Сужение (Contract) - деплой №3.***
	- После того, как убедились, что [[Rollback (Ролбэк, Откат) в CD|ролбэка]] не будет, убираем мусор => удаляем старую колонку.
