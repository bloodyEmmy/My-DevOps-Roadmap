#flashcards/automation/Ansible 
***
Ключевые настройки и данные, которые передаются [[Module (Модуль) в Ansible|модулю]], чтобы управлять его поведением и указывать, какую именно задачу нужно выполнить над каким объектом.
- То есть, это просто конкретные указания для программы.
***
***Пример.***
Рассмотрим модуль [[Apt модуль Ansible|apt]].
```yaml
- name: установка git   # 1
  apt:                  # 2
    name: git           # 3
    state: present      # 4
```
1. Имя [[Tasks (Таски, Задачи) в Ansible|таски]].
2. Имя модуля (здесь он для работы с [[Пакет|пакетами]] Ubuntu).
3. Параметр - какой пакет нужен.
4. Параметр - статус (должен быть установлен).
