#flashcards/monitoring/Prometheus 
***
[[Скрапер]] не может просто забирать данные как и откуда хочет. Для этого должны быть выполнены следующие условия:
1. В `prometheus.yml` должны быть корректно указаны [[Таргеты в Prometheus|таргеты]], по которым скрапер будет ходить и опрашивать их на предмет новых данных (см. [[Pull Model]]).
2. Также должны быть [[Endpoint|эндпойнты]] - конкретные [[Uniform Resource Locator (URL)|URL]]-пути на таргете, по которому доступны метрики. По умолчанию в [[Prometheus]] зашит [[Эндпойнт metrics в Prometheus|/metrics]].
3. Приложение на эндпойнте должно выдать ответ в строго отведенном формате, который сможет прочитать Прометей - стандарт ***OpenMetrics***.
