#flashcards/monitoring/Loki 
***
Самый умный раздел [[Loki Config|loki-config.yml]], нужный для задания архитектуры хранения данных: как именно [[Loki]] будет хранить, [[Индексирование|индексировать]] и раскладывать по папкам [[Чанк (Chunk)|чанки]] и логи.
- По сути - это список правил `configs:`, которые привязываются к дате.
***
***Реализация.***
```yml
schema_config:
  configs:
    - from: "2024-01-01"         # 1
      store: tsdb                # 2
      object_store: filesystem   # 3
      schema: v13                # 4
      index:
        prefix: index_           # 5
        period: 24h              # 6
```
1. Задаем дату, от которой идет действие правил, описанных ниже. Это нужно для того, чтобы не переписывать настройки для старых файлов и алгоритмов работы => поставили новую дату и прописываем новые настройки.
2. Название конкретного движка (формата) БД, который будет использован для хранения индексов (в примере - [[TSDB]], можно использовать, например, [[BoltDB]]).
3. Указывается физический тип носителя информации (`filesystem` = обычный жесткий диск, может быть и `s3` для AWS или MinIO). Подробную адресацию в рамках этого носителя мы прописывали в [[Common в Loki Config|common]].
4. Версия Loki и его организации данных.
5. Приставка перед именем для поиска.
6. Раз в это время будет создаваться новый файл логов вместо того, чтобы все валить в один и потом искать в нем данные.
