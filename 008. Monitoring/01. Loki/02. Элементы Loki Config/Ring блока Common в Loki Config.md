#flashcards/monitoring/Loki 
***
Один из элементов блока [[Common в Loki Config|common]], который прописывается внутри [[Loki Config|loki-config.yml]].
- Отвечает за настройку [[Хеш кольцо (Hashing Ring)|хеш кольца]].
***
***Реализация.***
```yml
common:
  ring:                        # 1
    instance_addr: 127.0.0.1   # 2
    kvstore:                   # 3
      store: inmemory          # 4
```
1. Пишем, что настраиваем кольцо.
2. Прописываем адрес, которым [[Loki]] будет регистрировать себя внутри [[Кластер|кластера]].
	- Если хост один, то можно прописать и [[Loopback (Localhost)|localhost]] - ***тогда работа будет вестись в единственном [[Контейнер|контейнере]] Loki***.
	- В противном случае нужен реальный [[IP-адрес]] сервера, используемого в данной [[Драйвер Overlay в Docker|overlay]]-сети.
3. Настраиваем [[KV хранилище (KV Store, Consul KV)|KV-хранилище]] для Loki.
4. Говорим, что можно хранить данные в [[Оперативная память (ОЗУ)|ОЗУ]] - хост только 1, поэтому нам не нужны внешние сложные [[Etcd]], [[Consul]] и др.
