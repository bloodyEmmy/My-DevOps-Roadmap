#flashcards/monitoring/Loki 
***
Блок внутри [[Loki Config|loki-config.yml]].
- Отвечает за то, как [[Loki]] общается с внешним миром по сети.
***
***Реализация.***
```yaml
server:
  http_listen_port: 3100 # 1
  grpc_listen_port: 9096 # 2
```
Мы открываем два сетевых [[Порт|порта]] на настраиваемом хосте.
1. Главный порт, работающий по классическому [[Протокол HTTP|HTTP]], через который:
	- Grafana подключается к Loki для поиска логов в браузере.
	- [[Docker]] шлет логи [[Контейнер|контейнеров]] при помощи своего [[Драйвер журналирования (логирования)|драйвера логирования]].
2. Внутренний технический порт, который работает [[Протокол уровня|протокол]] gRPC.
	- Используется для внутренних задач и общения с другими сборщиками логов.
