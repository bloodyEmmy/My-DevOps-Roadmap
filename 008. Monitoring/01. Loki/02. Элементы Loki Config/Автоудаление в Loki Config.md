#flashcards/monitoring/Loki
***
Блок настроек в [[Loki Config|loki-config.yml]], который нужен для задания [[Зачем нужно автоматическое удаление логов|автоматического удаления логов]].
- Состоит из двух частей.
***
***Реализация.***
```yml
limits_config:
  retention_period: 168h               # 1
  
compactor:                             # 2
  working_directory: /loki/compactor   # 3
  retention_enabled: true              # 4
```
1. Указываем время жизни логов [[Loki]] (в нашем случае - 7 дней). Ставится в часах (пример - `720h` = месяц).
2. Задаем настройки [[Компактор|компактора]].
3. Временные расчеты компактора перед удалением старых файлов.
4. Разрешение на удаление старых [[Чанк (Chunk)|чанков]] (по умолчанию выключен).
