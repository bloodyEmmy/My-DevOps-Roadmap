#flashcards/os/Unix
***
У [[Ядро операционной системы|ядра]] есть единое дерево каталогов и файлов, которое стартует с `/`.
Ядро ведет ***таблицу монтирования***, чтобы видеть, куда подключена флешка, физический диск и др. И обычно все [[Процесс|процессы]] хоста, имея один PID в [[Proc (VFS)|proc]], смотря в одну глобальную таблицу.
- Такие [[Пространства имен (namespaces)|namespaces]] создают для процесса свою личную копию таблицы => у процесса есть своя таблица маршрутов, мини-[[Файловая система|файловая система]], которую он может менять и не ломать основной хост.
- По большей части такая изоляция используется в [[Docker]] при работе, например, с [[Bind Mount (Монтирование каталогов с хоста)|биндом]] и [[Том Docker|томами]].
***
***Алгоритм работы в Docker.***
1. Docker просит ядро создать личную копию системы, берет эту таблицу и переписывает для нее правило для корня `/`.
2. Теперь для этого процесса его личный корень `/` лежит в какой-нибудь отдельной директории, например `/var/lib/docker/overlay2/<ID>/` (см. [[Директория слоя (overlay2)|overlay2]]).
3. Теперь процесс не может выйти из своей системы, так как не имеет адреса до нее.
