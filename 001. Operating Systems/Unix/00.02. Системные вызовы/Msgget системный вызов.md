#flashcards/os/Unix 
***
[[Системный вызов]] в [[Unix]]-подобных системах, который используется для создания новой [[Очередь сообщений|очереди сообщений]] или получения доступа к уже существующей.
- По сути, это тот же [[Open системный вызов|open()]] для файлов, только для очереди - мы превращаем абстрактный внешний адрес (в нашем случае [[IPC ключ]]) в рабочий внутренний [[Файловый дескриптор (FD)|дескриптор]].
***
***Реализация.***
```C
#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>

int msgget(key_t key, int msgflg);
```
- `key` - числовой [[Идентификация|идентификатор]], который связывает [[Процесс|процессы]] с конкретной очередью (наш IPC-ключ). Он передается с помощью используемой заранее [[Ftok системный вызов|ftok]].
- `msgflg` - параметр, определяющий поведение вызова и [[Права доступа к файлу|права доступа]] к очереди. Состоит из нескольких частей:
	1. Права доступа - задаются в [[Chmod с использованием восьмеричных чисел|восьмеричной системе]] (примеры - `0666` или `0600`).
	2. `IPC_CREAT` - [[Макропроцессор (Макрос)|макрос]], который говорит [[Ядро операционной системы|ядру ОС]]: "Если очереди с таким ключом нет - создай. Иначе - открой ее и верни ID".
	3. `IPC_EXCL` - используется только с `IPC_CREAT`, говорит ядру: "Создай очередь. Если очередь с таким ID есть, верни `-1`".
***
***Пример.***
```C
key_t key = ftok(".", 'A');
int msqid = msgget(key, IPC_CREAT | IPC_EXCL | 0666);
if (msqid == -1) {
    perror("Очередь уже существует или произошла ошибка");
    msqid = msgget(key, 0666);
}
else {
    printf("Сервер успешно создал новую очередь с ID: %d\n", msqid);
}
```
