#flashcards/os/Unix 
***
[[Системный вызов]], который находит нужное сообщение в связном списке [[Ядро операционной системы|ядра ОС]], копирует его в память процесса и удаляет узел из [[Связный список|списка]].
***
***Синтаксис.***
```C
#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>

ssize_t msgrcv(int msqid, void *msgp, size_t msgsz, long msgtyp, int msgflg);
```
- `msqid` - идентификатор [[Очередь сообщений|очереди сообщений]].
- `msgp` - указатель на структуру в памяти [[Процесс|процесса]], куда ядро копирует данные.
- `msgsz` - максимальный размер [[Буфер|буфера]] данных с ***полезной информацией***.
- `msgtyp` - параметр фильтрации (выборки из очереди).
	1. `0` - читать строго первое сообщение в очереди (обычный `FIFO`).
	2. `> 0` - читать первое сообщение, у которого поле `mtype` равно указанному числу (пример - [[Клиент (Клиент Серверная Архитектура)|клиент]] читает только сообщения под номером 3).
	3. `< 0` - читать первое сообщение с наименьшим типом, который <= абсолютному значению `msgtyp`.
- `msgflg` - флаги поведения.
	1. `0` - блокирующий режим, если сообщения с нужным типом в очереди нет, процесс засыпает.
	2. `IPC_NOWAIT` - если сообщений нет, то вернуть ошибку `-1`.
	3. `MSG_NOERROR` - если сообщение длиннее буфера, то ядро обрезает сообщение до длины буфера.
