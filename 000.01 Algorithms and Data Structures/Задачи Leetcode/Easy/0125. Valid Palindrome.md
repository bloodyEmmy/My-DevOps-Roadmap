Фраза называется **палиндромом**, если после преобразования всех заглавных букв в строчные и удаления всех небуквенно-цифровых символов она читается одинаково как в прямом, так и в обратном порядке. К буквенно-цифровым символам относятся буквы и цифры.
Если задана строка `s`, вернуть значение, `true`_если она является **палиндромом** , или_ `false`_значение в противном случае_ .
***Пример 1.***
Входные данные: `s = "A man, a plan, a canal: Panama"`
Выходные данные: `true`
Пояснение: "amanaplanacanalpanama" — палиндром.
***Пример 2.***
Входные данные: `s = "race a car"`
Выходные данные: `false`
Пояснение: "raceacar" не является палиндромом.

В качестве решения используем метод [[Метод двух указателей (Two Pointers)|Two Pointers]], а именно [[Два встречных указателя|встречные указатели]].
- Временная сложность составляет [[O-большое|O(n)]], так как один раз проходимся по строке.
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        s = s.lower().split()
        s = "".join(s)
        n = len(s)
        left, right = 0, n - 1
        while left < right and left < n and right > -1:
            if s[left].isalnum() == False:
                left += 1
            elif s[right].isalnum() == False:
                right -= 1
            elif s[left] != s[right]:
                return False
            else:
                left += 1
                right -= 1
        return True
```
1. Убираем из строки все пробелы, переводим символы в нижний регистр, заводим два указателя слева и справа.
2. При помощи [[Isalnum Python|isalnum()]] проверяем, что символ является цифрой или буквой, в противном случае сдвигаем указатель.
3. Если проверка `isalnum()` пройдена, то сверяем 2 символа, после чего при равенстве сдвигаем оба к центру.
