Дана неотсортированная последовательность целых чисел `nums`. Верните длину самой длинной последовательности последовательных элементов.
Вам необходимо написать алгоритм, который работает за  `O(n)` время.
***Пример 1.***
Входные данные: `nums = [100,4,200,1,3,2]`
Выходные данные: `4`
Пояснение: Самая длинная последовательность последовательных элементов — `[1, 2, 3, 4]`. Следовательно, её длина равна `4`.
***Пример 2.***
Входные данные: `nums = [0,3,7,2,5,8,4,6,0,1]`
Выходные данные: `9`
***Пример 3.***
Входные данные: `nums = [1,0,1,2]`
Выходные данные: `3`

Здесь есть одна важная теоретическая загвоздка - сложность [[O-большое|O(n)]] подразумевает один большой проход через `for`, однако при этом внутри него можно использовать `while`, который работает не со всеми элементами `nums` => это все еще считается за `O(n)`.
```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        s = set(nums)
        ans = 0
        for number in s:
            if (number - 1) not in s:
                current_ans = 0
                while number in s:
                    number += 1
                    current_ans += 1
                ans = max(ans, current_ans)
        return ans
```
1. Создаю [[Словарь в Python|словарь]] из `nums`, потому что в нем поиск через `in` происходит моментально.
2. Прохожусь по элементам и отбираю среди них только те, которые являются началом очереди, то есть число перед ними (на 1 меньше) не содержится в `nums`.
3. Для таких запускаю `while`, в котором делаю +1 для значения числа (и проверки его наличия в словаре), а также +1 к счетчику.
