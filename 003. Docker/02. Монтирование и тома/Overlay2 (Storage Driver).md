[[Драйвер хранилища (Storage Driver)|Драйвер хранилища]] внутри [[Docker]].
- Используется в Docker по умолчанию => самый популярный [[Драйвер|драйвер]].
- Нужен для работы с [[Файловая система|файловой системой]] [[Unix]] по умолчанию - `ext4`.
- Переводит команды Docker в инструкции для модуля [[Ядро операционной системы|ядра]] [[OverlayFS]].
