#flashcards/Docker 
***
По сути, это та же самая группа [[Контейнер|контейнеров]] (то есть [[Сервис в Swarm|сервисов]]), которые работают как единое приложение на разных хостах, при этом управляясь одной командой и стартуя базовым [[Stack deploy команда Swarm|stack deploy]] из `docker-compose.yml` файла [[Docker Compose]].
- Разницы особой нет, просто на его основе есть несколько команд, созданных специально для работы с развернутым приложением из одного файла на целом [[Кластер|кластере]] хостов.
***
***Пример.***
- Пусть у нас есть приложение, созданное из нескольких [[Микросервис|микросервисов]]: сайт + база данных [[PostgreSQL]] + Grafana + какой-нибудь балансировщик, например [[Nginx]].
- Запускать каждый из них одной командой [[Service create команда Swarm|service create]] - бред, мы не сможем настроить их, пробросить [[Порт|порты]], зависимости и др.
- Используем стек - просто описываем логику каждого сервиса в одном файле `.yml`, после чего запускаем через `stack deploy`.
