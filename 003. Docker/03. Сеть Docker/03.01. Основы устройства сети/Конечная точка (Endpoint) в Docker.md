#flashcards/Docker
***
Связующее звено между [[Песочница (Sandbox) Docker|песочницей]], принадлежащей [[Контейнер|контейнеру]], и сетью [[Docker]], абстракция виртуальной [[Сетевая карта|сетевой карты]], вставленной в контейнер.
- В [[Container Network Model (CNM)|CNM]] это один из концов либо виртуального [[Virtual Ethernet Pair (Veth)|veth]]-кабеля, либо с другой стороны [[docker0]].
- Проще - это просто розетка, через которую контейнер может стучаться в сеть.
- При удалении контейнер будет жив, но потеряет связь с реальностью.
***
***Задачи.***
- Соединение песочницы с сетью + передача данных.
- Обеспечивает изоляцию - принадлежит только одному контейнеру / сети.
- Обрабатывает сетевой трафик контейнера, [[Маршрутизация|маршрутизируя]] его в сеть и обратно.
- Регистрация контейнера в сети + назначение [[IP-адрес|IP]] и [[MAC-адрес|MAC-адреса]] в пределах сети.
***
***Конечные точки, подключенные к одной сети, взаимодействуют друг с другом.***
- Про другие endpoint-ы читаем [[Endpoint|здесь]].
