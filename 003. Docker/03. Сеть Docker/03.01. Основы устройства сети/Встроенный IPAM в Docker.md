#flashcards/Docker
***
Внутренняя подсистема ([[Драйвер|драйвер]]) в [[Docker]], которая отвечает за автоматическое распределение, учет и освобождение [[IP-адрес|IP-адресов]], [[Маска подсети|масок подсетей]] и шлюзов для [[Контейнер|контейнеров]].
- Мы не назначаем контейнерам IP для работы в сети - Docker сам выделяет адрес, а при удалении контейнера - забирает обратно.
- По умолчанию используется встроенный `default`, но [[Container Network Model (CNM)|CNM]] позволяет подключить любой.
***
***Причина появления.***
Аналогично с [[docker0]], мы могли бы использовать встроенный на хосте [[IP Adress Management (IPAM)|IPAM]] - обычно это [[Протокол DHCP|DHCP]]-[[Клиент (Клиент Серверная Архитектура)|клиент]], который запрашивает адрес у [[Маршрутизатор (Роутер)|роутера]].
Мы используем свой IPAM, потому что:
1. Контейнеры существуют короткое время, перезапускаются и удаляются => классический IPAM не настроен под такую скорость.
2. Нет выхода на роутер и куда-либо извне хоста.
3. Исключение конфликтов в [[Микросервис|микросервисах]] - например в работе с [[Docker Compose]] есть предсказуемость структуры сети, адресов и др.
