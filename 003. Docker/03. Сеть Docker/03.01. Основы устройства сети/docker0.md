#flashcards/Docker
***
Единственный [[Сетевой мост (Bridge)|сетевой мост]] по умолчанию, который создается при установке Docker.
- Появляется автоматически при старте [[Docker Engine]].
- Все [[Контейнер|контейнеры]], которые запускаются без параметров сети, попадают именно в `docker0`.
***
***Функции.***
1. ***Локальный [[Коммутатор (switch)|коммутатор]]*** - объединяет все контейнеры в одну виртуальную [[Подсеть|подсеть]] (обычно `172.17.0.0/16`) => контейнеры могут общаться друг с другом по [[IP-адрес|IP-адресам]] через этот мост.
2. [[Шлюз по умолчанию (Default Gateway)|Шлюз по умолчанию]] - для контейнеров интерфейс `docker0` является выходом во внешний мир из [[Подсеть|подсети]], а сам мост обычно имеет адрес `172.17.0.1`.
3. ***Автоматический [[Network Address Translation (NAT)|NAT]] (Маскарадинг)*** - [[Docker]] настраивает правила `iptables` на хосте => когда контейнер идет во внешний мир, его внутренний IP подменяется внешним IP хоста.
***
***Важно.***
Мы используем `docker0`, а не обычный [[Unix]]-мост, потому что это дает нам предсказуемость в работе, безопасность и изоляцию (при взломе контейнеров нет доступа ко всей сети на хосте), управление правилами [[Межсетевой экран (Брандмауэр, Firewall)|Firewall]] и др.
- Также важно то, что мост получает IP-адреса, обычно, через [[Протокол DHCP|DHCP]] роутера, в то время как Docker сам раздает адреса => могут быть конфликты, если использовать один мост.
