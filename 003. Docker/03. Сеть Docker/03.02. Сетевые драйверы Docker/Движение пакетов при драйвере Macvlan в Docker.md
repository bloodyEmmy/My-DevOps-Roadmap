#flashcards/Docker 
***
Пусть смартфон (`192.168.1.20`) отправляет запрос [[Контейнер|контейнеру]] (`192.168.1.55`).
1. Смартфон шлет пакет по [[Wi-Fi]] на [[IP-адрес]] контейнера.
2. [[Маршрутизатор (Роутер)|Роутер]] делает [[Протокол ARP|ARP]]-запрос "У кого IP 192.168.1.55?", контейнер через физическую [[Сетевая карта|сетевую карту]] хоста шлет ответ и свой [[MAC-адрес]], роутер запоминает это.
3. Роутер кидает пакет в физический провод на хост, сетевая карта `eth0` принимает пакет, смотрит на MAC-адрес получателя.
4. После чего [[Ядро операционной системы|ядро]] перенаправляет пакет в [[Песочница (Sandbox) Docker|песочницу]] контейнера.
