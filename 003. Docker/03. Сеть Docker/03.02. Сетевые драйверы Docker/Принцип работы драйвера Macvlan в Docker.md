#flashcards/Docker 
***
При активации [[Драйвер|драйвера]] [[Драйвер Macvlan в Docker|macvlan]]:
1. [[Ядро операционной системы|Ядро]] берет физический интерфейс (пример: `eth0`) и переводит его в режим, позволяющий [[Сетевая карта|сетевой карте]] иметь несколько разных [[MAC-адрес|MAC-адресов]] одновременно.
2. Для [[Контейнер|контейнера]] создается виртуальный интерфейс, который растет из физической карты хоста.
3. Этот интерфейс [[Docker]] кладет в сетевую [[Песочница (Sandbox) Docker|песочницу]] контейнера, а также полностью отключает [[Фреймворк Netfilter|Netfilter]] (iptables) и [[Network Address Translation (NAT)|NAT]].
4. [[Сетевой мост (Bridge)|Мост]] [[docker0]] не участвует в схеме, пакеты из контейнера прыгают на драйвер физического сетевого чипа.
