#flashcards/Docker 
***
***Если кто-то из Интернета отправляет, например, [[Протокол HTTP|HTTP]]-[[Методы (запросы) HTTP|запрос]] на [[Порт|порт]] 80, то:***
1. Сетевой пакет прилетает на физический порт [[Сетевая карта|сетевой карты]] `eth0`.
2. [[Ядро операционной системы|Ядро]] Linux принимает пакет, смотрит на таблицу портов и видит, каким [[Процесс|процессом]] он открыт.
3. Ядро передает данные процессу. То, что внутри него [[Docker]]-[[Контейнер|контейнер]], не проблема для него.
4. Пакет обрабатывается по обычному алгоритму на обычной скорости [[Процессор (CPU)|процессора]] и сетевой карты.
