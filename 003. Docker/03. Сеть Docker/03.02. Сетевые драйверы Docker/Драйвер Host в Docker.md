#flashcards/Docker
***
[[Драйвер]], который отключает сетевую изоляцию [[Контейнер|контейнера]].
То есть контейнер начинает использовать сетевой стек самого хоста напрямую.
- При работе не нужно пробрасывать [[Порт|порты]] (пример: `-p 80:80`), контейнер сам займет нужный реальный порт хоста.
- Если у хоста есть и [[IP-адрес]], например `192.168.1.100`, то контейнер станет доступен по адресу `http://192.168.1.100:80` (вспоминаем [[Протокол HTTP|HTTP]]).
***
***Принцип работы.***
1. Обычно [[Docker]] при создании процесса просит [[Ядро операционной системы|ядро]] изолировать [[Процесс|процессы]] (см. [[PID Namespace (Изоляция дерева процессов)|здесь]]), файлы ([[Mount Namespace (Изоляция файловой системы)|здесь]]) и сеть (network [[Пространства имен (namespaces)|namespace]]).
2. При выборе `host` Docker по-прежнему изолирует файлы и процессы контейнера, чтобы приложение не видело другие файлы и программы.
3. Но при этом не создается новой сетевой [[Песочница (Sandbox) Docker|песочницы]], Docker указывает ядру запускать процессы внутри дефолтного сетевого пространства хоста.
4. ***Итог*** - у контейнера нет своего IP, [[Virtual Ethernet Pair (Veth)|veth]]-провода, он не подключен ни к какому [[Сетевой мост (Bridge)|мосту]].
***
***Активация.***
```bash
docker run -d --network host nginx
```
- Использованы [[Run команда Docker|run]] и [[Nginx]].
