#flashcards/Docker
***
[[Драйвер]], который привязывает виртуальные интерфейсы [[Контейнер|контейнеров]] напрямую к физической [[Сетевая карта|сетевой карте]] хоста.
- Каждый контейнер получает свой уникальный физический [[MAC-адрес]] и реальный [[IP-адрес]] из сети хоста.
- По умолчанию хост и его собственные контейнеры не могут общаться => ***[[Ping команда терминала|ping]] не пройдет***.
***
***Пример.***
- Пусть есть хост, подключенный к [[Маршрутизатор (Роутер)|роутеру]], который раздает адреса в сети `192.168.1.0/24`. Сам хост имеет IP `192.168.1.10`.
- После создания `macvlan` и указания, к какой физической карте ее привязать, мы можем запустить контейнер.
- ***Итог*** - роутер думает, что к нему в порт воткнули еще один отдельный хост с MAC-адресом контейнера => если мы запускали, например, [[Nginx]], то мы можем зайти на `http://<IP контейнера>` с телефона, подключенного к [[Wi-Fi]].
- Получили, что пакеты летят напрямую через роутер, минуя фильтры [[Docker]].
***
***Активация.***
1. Создание сети `macvlan` + указание физической карты через [[Network команда Docker|network]].
```bash
   docker network create -d macvlan \
  --subnet=192.168.1.0/24 \
  --gateway=192.168.1.1 \
  -o parent=eth0 my_macvlan_net
```
2. Запуск контейнера в сети через [[Run команда Docker|run]].
```bash
docker run -d --network my_macvlan_net --ip 192.168.1.55 nginx
```
