#flashcards/Docker
***
Позволяет работать с сетями.
***Синтаксис.***
```bash
docker network <команда> <опции>
```
- `<опции>` - часто имя сети.
***
***Команды.***
1. `create` - создание сети.
2. `ls` - просмотр сетей.
3. `inspect <имя>` - детали в JSON (как в [[Inspect команда Docker|inspect]]).
4. `docker run --network <контейнер>` - подключение [[Контейнер|контейнера]] к сети при его запуске.
5. `docker network connect <сеть> <контейнер>` - подключение РАБОТАЮЩЕГО контейнера.
6. `docker network disconnect <сеть> <имя>` - отключение контейнера от сети
7. `rm <имя>` - удаление сети.
8. `--driver <драйвер>` - пишем используемый [[Сетевые драйверы Docker|сетевой драйвер]], прим `driver bridge` - [[Драйвер Bridge в Docker|bridge]].
