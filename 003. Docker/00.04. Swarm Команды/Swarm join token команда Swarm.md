#flashcards/Docker
***
Показывает [[Токен|токен]] и команду для присоединения [[Узел в Swarm (Нода, Node)|узлов]] к [[Кластер|кластеру]].
***Синтаксис.***
```bash
docker swarm join-token <опции> <worker|manager>
```
- `worker` - показать токен для [[Рабочий узел (worker node) в Swarm|рабочего]].
- `manager` - показать токен для [[Управляющий узел (manager node, менеджер) в Swarm|менеджера]].
***
***Флаги.***
1. `--rotate` - генерирует новый токен. Старый перестает работать. ***УЖЕ ПОДКЛЮЧЕННЫЕ УЗЛЫ РАБОТАЮТ КАК ПРЕЖДЕ.***
2. `--quiet (-q)` - вывести только токен без полной команды.
