#flashcards/Docker
***
Позволяет работать с [[Узел в Swarm (Нода, Node)|узлами]] в [[Кластер|кластере]].
***Синтаксис.***
```bash
docker node <команды> <опции>
```
- `<опции>` для каждой команды рассматриваются отдельно.
***
***Команды.***
1. `ls` - показать список всех узлов в кластере.
	***Флаги.***
		1. `--filter (-f)` - фильтрует вывод по условию (пример: `role=manager`).
		2. `--format` - форматирует вывод по условию.
		3. `--quiet (-q)` - выводит только ID узлов.
2. `inspect <NODE>` - детальная инфа об узле (аналог [[Inspect команда Docker|inspect]]).
	***Флаги.***
		1. `--pretty` - показывает инфу в читаемом виде.
		2. `--format` - извлекает конкретное поле (прим: `--format '{{.Status.State}}'`)
3. `promote <NODE>` - повышает [[Рабочий узел (worker node) в Swarm|рабочий узел]] до [[Управляющий узел (manager node, менеджер) в Swarm|менеджера]].
4. `demote <NODE>` - понижает менеджера до рабочего.
5. `rm` - удаляет узел из списка кластера.
	Флаг: `--force (-f)` - принудительное удаление (после [[Swarm leave команда Swarm|swarm leave]]).
6. [[Опция update команды node Swarm|Опция update]].
