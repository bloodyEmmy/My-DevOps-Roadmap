По сути, аналогия [[Типы Mac-адресов|типов]] у [[MAC-адрес|MAC-адресов]].
1. Индивидуальный (unicast) - адрес конкретного компьютера в сети.
2. Групповой (multicast) - адрес, используемый несколькими компьютерами (например, [[Кластер|кластер]]). Данные получают все ПК, находящиеся в этой группе.
3. [[Широковещательный (broadcast) тип IP-адреса|Широковещательный]].
