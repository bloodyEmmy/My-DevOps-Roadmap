#flashcards/network 
***
Метод [[Маршрутизация|маршрутизации]] в децентрализованных сетях, при которой узел внутри сети (пример: [[Ad Hoc сеть|Ad-Hoc]]) отправляет пакет всем своим соседям сразу, а каждый получивший узел копирует его и пересылает всем своим соседям дальше.
- Возникает опасность появления [[Широковещательный шторм (Broadcast Storm)|широковещательного шторма]] - пакеты могут бесконечно ходить по кругу между узлами.
- Для решения это проблемы используется правило - ***если узел уже получал и пересылал этот пакет ранее, то он его игнорирует и не высылает заново***.
- То есть у каждого узла в памяти есть только список ID ([[Идентификация|идентификаторов]]) пакетов, которые он уже пересылал, чтобы не гонять их заново.
- Однако все равно есть риск возникновения шторма. Подробнее - [[Широковещательный шторм при лавинной маршрутизации|здесь]].
***
***Плюсы.***
1. Пакет идет по всем возможным путям одновременно => если часть узлов выйдет из строя, получатель все равно сможет поймать данные.
2. Узлам не надо строить тяжелые [[Таблица маршрутизации|таблицы маршрутизации]].
3. Идеальный метод введения нового узла в сеть.
