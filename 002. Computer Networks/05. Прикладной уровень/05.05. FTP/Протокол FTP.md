#flashcards/network 
***
***Расшифровка:*** File Transfer Protocol.
Протокол [[Прикладной уровень|прикладного уровня]] для передачи данных между хостами.
- Отвечает исключительно за логику взаимодействия пользователя и [[Файловая система|файловой системы]] удаленного [[Сервер (Клиент Серверная Архитектура)|сервера]].
- Жестко основан на протоколе [[Протокол TCP|TCP]], потому что передача файлов требует стопроцентной гарантии доставки, сохранения порядка следования пакетов и контроля [[Перегрузка в TCP|перегрузок]] - [[Протокол UDP|UDP]] не справляется с этими задачами - потеря любого символа делает содержимое файла некорректным.
