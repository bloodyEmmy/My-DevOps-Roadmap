#flashcards/Docker
***
Изолирует [[Контейнер|контейнер]] от цифрового мира на 100%.
После [[Start команда Docker|старта]] при попытке связаться из контейнера с сайтами через [[Ping команда терминала|ping]] или [[Curl команда терминала|curl]] получим ошибку о недоступности сети => контейнер не может связаться ни с Интернетом, ни с хостом, ни с другими контейнерами.
***
***Принцип работы.***
1. При [[Create команда Docker|создании]] контейнера [[Ядро операционной системы|ядро]] создает для контейнера персональную сетевую [[Песочница (Sandbox) Docker|песочницу]].
2. При этом не создается [[Virtual Ethernet Pair (Veth)|veth]]-кабель, также [[Docker]] не подключает контейнер ни к какому [[Сетевой мост (Bridge)|мосту]] (пример: [[docker0]]).
3. Docker не подключает контейнеру и [[Встроенный IPAM в Docker|IPAM]] - у него совсем нет [[IP-адрес|IP-адреса]].
4. Внутри песочницы контейнера создается только один интерфейс - `lo` ([[Loopback (Localhost)|localhost]]) с адресом `127.0.0.1`.
5. ***Итог*** - пакет никогда не покидает пределы [[Оперативная память (ОЗУ)|ОЗУ]], выделенной под песочницу контейнера.
6. При попытке выйти из песочницы, сетевой стек смотрит на [[Таблица маршрутизации|таблицу маршрутизации]] - она пустая, нет даже [[Шлюз по умолчанию (Default Gateway)|шлюза по умолчанию]] => ядро уничтожает пакет и возвращает ошибку.
***
***Активация.***
```bash
docker run -it --network none alpine sh
```
- Использована команда [[Run команда Docker|run]].
