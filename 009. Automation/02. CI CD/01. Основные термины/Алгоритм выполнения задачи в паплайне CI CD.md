#flashcards/automation/cicd
***
1. Система контроля версий (GitHub, GutLab и др.) фиксирует изменение кода.
2. На выделенном сервере в чистом [[Окружение|окружении]] запускается процесс [[Интерпретатор|интерпретатора]] командной строки (пример: `/bin/bash`).
3. [[Процесс|Процессу]] передается набор инструкций из файлов разработчика.
4. Происходит [[Транслятор|трансляция]], система читает [[Ввод, вывод, вывод ошибок|потоки вывода]] (`stdout` + `stderr`) [[Bash|bash]]-процесса и перенаправляет их в веб-интерфейс, чтобы мы видели логи в реальном времени.
5. Результат работы [[CI CD Pipeline (Пайплайн)|пайплайна]] зависит от кода возврата (***exit code*** - [[Управление статусом (Exit Code) в CI|здесь]]) - либо `0` (этап успешный), либо ненулевое значение (пример: `exit 1`) при ошибке => процесс убивает, пайплайн падает `failed`.
