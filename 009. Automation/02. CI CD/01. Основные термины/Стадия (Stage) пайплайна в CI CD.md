#flashcards/automation/cicd
***
Логический этап автоматического [[CI CD Pipeline (Пайплайн)|пайплайна]] в [[CI CD]], который объединяет группу связанных [[Задача (Job) пайплайна в CI CD|задач]] для достижения конкретной цели в процессе доставки кода.
- ***Аналогия:*** если пайплайн - это заводской конвейер, то стадии - это отдельные цеха => пока детали не пройдут через один цех, они не попадут в другой.
- Особенность - строгая последовательность.
- Если на этапе происходит сбой, то весь пайплайн останавливается с ошибкой.
***
***Ключевые стадии.***
1. ***Build (Сборка)*** - исходный код качается из репозитория, [[Компилятор|компилируется]], подтягиваются зависимости и создается готовый [[Артефакты в CI CD|артефакт]].
2. ***Test (Тестирование)*** - запуск проверок.
3. ***Release / Package (Упаковка)*** - сборка сохраняется в хранилище артефактов (Registry) и маркируется версией.
4. ***Deploy (Развертывание, [[Деплой]])*** - приложение публикуется на сервера - сначала на тестовые (Stage / Dev), а после финальных проверок - на [[Продакшн (Prod, Production)|проде]].
