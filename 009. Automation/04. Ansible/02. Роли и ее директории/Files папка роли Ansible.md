#flashcards/automation/Ansible 
***
Директория, которая по умолчанию создается при задании новой [[Роль в Ansible|роли]].
- В ней содержатся все статические файлы, которые передаются на [[Сервер (Клиент Серверная Архитектура)|сервер]] байт в байт при помощи, например, [[Copy модуль Ansible|copy]].
- [[Ansible]] не заходит внутрь этих файлов, не меняет их содержимое - это просто место для картинок, бинарников и скриптов, которые никогда не меняются.
***
***Пример.***
```yml
- name: Доставляем статику
  copy:
    src: main.py # Модуль copy сам пойдет искать этот файл в папке files/
    dest: /opt/watchdog/main.py
```
