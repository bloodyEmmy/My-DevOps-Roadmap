#flashcards/automation/IaC 
***
Один из способов давать инструкции по настройке компьютеру.
- Мы описываем последовательность конкретных команд и действий, которые нужно выполнить по очереди.
***
***Пример.***
```bash
apt update
apt install -y nginx
systemctl start nginx
```
- Установили и запустили [[Nginx]].
***
***Минус.***
- Скрипт глупый, если мы его запустим на сервере, на котором уже есть Nginx, то он все равно будет заново скачивать [[Пакет|пакеты]] и перезапускать службу => может произойти сбой => не выполняется принцип [[Идемпотентность|идемпотентности]].
