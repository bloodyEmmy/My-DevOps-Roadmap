#flashcards/automation/Vagrant 
***
Позволяет работать со всеми [[Boxes (Боксы) в Vagrant|боксами]], которые используются [[Виртуальная машина|виртуалками]] на всем хосте, а не только в рамках текущей директории с [[Vagrantfile]].
- Напоминает чем-то [[Docker]] с его командой [[Image команда Docker|image]] или [[Images команда Docker|images]] для работы с [[Образ контейнера (Docker Image)|образами]].
***
***Пример.***
```bash
vagrant box list              # 1
vagrant box update --global   # 2
```
1. Показывает список всех используемых боксов.
2. Проверяет наличие обновлений для боксов.
