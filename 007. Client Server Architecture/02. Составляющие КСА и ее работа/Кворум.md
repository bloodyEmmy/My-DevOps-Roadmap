#flashcards/clientserver 
***
Состояние [[Кластер|кластера]] во время голосования, при котором можно четко назвать [[Сервер (Клиент Серверная Архитектура)|сервер]]-кандидат на избираемую роль.
- Играет важнейшую роль в [[Raft]], который используется в [[Docker Swarm]] для выбора [[Лидер в Docker Swarm|лидера]], [[Consul]] и др.
***
***Главное правило.***
Количество хостов на одной стороне для достижения кворума должно быть равно `N / 2 + 1`, где `N` - общее количество голосующих.
- Если есть две группы серверов с одинаковым количеством участников в каждой, то получаем [[Split Vote (Разделение голосов)|разделение голосов]].
- Именно поэтому обычно в кластер берут нечетное количество хостов.
